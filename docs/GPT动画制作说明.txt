制作流程

1. 在编辑器保存课件，点击「导出课件 JSON」。
2. 将导出的文件交给 GPT，选择「课件动画编排」Skill，或粘贴下面的提示词并填写教学要求。可以附页面截图。
3. 下载 GPT 返回的 JSON，在同一课件点击「导入动画变更」。
4. 校验通过后点击「预览动画」，返回编辑器后「确认保存动画」。也可以取消变更。
5. 若课件内容已变化，请重新保存、导出并生成变更。

动画清单和 Skill

导出文件的 allowed_effects 已包含当前可导入的全部元素动画，按入场、退场和强调分组。每次编排以本次导出的清单为准。
编辑器的「下载 GPT 动画 Skill」提供 SKILL.md。在支持创建 Skill 的 ChatGPT Work 中，可以用 @skill-creator 根据该文件创建一次，之后在新对话中用 @ 选中它，再附上课件 JSON。使用其他聊天入口时，可把 SKILL.md 作为当前对话的说明文件，或使用下面的提示词。

提示词及格式示例

请根据附件课件和我的教学要求编排动画，输出一个可下载的 JSON 文件。
输出格式为 {"format_version":1,"base_id":"原样复制导出文件的 base_id","changes":[{"slide_id":"原页面ID","animations":[{"id":"唯一动画ID","elId":"该页已有元素ID","type":"in","effect":"fadeIn","duration":1000,"trigger":"click"}]}]}。
每个 changes 项完整替换该页动画列表。请保留该页仍需使用的已有动画。省略的页面保留原动画，空数组会清空该页动画。
只使用 allowed_effects 中与 type 匹配的效果。duration 单位为毫秒，范围 100–10000。
trigger 可用 click（点击）、meantime（与上一动画同时）、auto（上一动画结束后）。每页第一条使用 click。同一并行动画组中每个元素只能出现一次。
只输出上述字段，保持页面和元素 ID，素材引用仅供理解。根据文字、元素位置和补充截图判断教学顺序。
请检查引用、效果、时长和动画顺序，返回完整变更 JSON。
我的教学要求：请在这里填写，例如标题点击淡入，三条要点依次点击出现。

素材说明

导出保留 HTTPS 外链及 asset 私有素材引用。GPT 无法直接通过 asset 引用查看素材，按需提供页面截图。每页 animations 完整替换该页动画，请检查 GPT 保留了需要保留的已有动画。
